## Ce qui change

- Les licences de Python 3.12 et SDL3 sont maintenant fournies intégralement
  dans les applications Windows et macOS.
- Les composants inclus sont séparés clairement des outils utilisés uniquement
  pour compiler ou tester le projet.
- La provenance de la carte, des données et des références éditoriales est
  documentée, avec la limite de droits restant à régler avant la version 1.0.
- Une politique de confidentialité décrit les fichiers locaux et les rares cas
  où une connexion Internet intervient.
- Le workflow bloque une release si un document obligatoire manque, si une
  dépendance auditée change ou si un actif inattendu est ajouté.

## Installation

- Windows 10/11 x64 : télécharger le fichier `Setup.exe`.
- macOS 14 ou plus récent sur Apple Silicon : télécharger le fichier `.dmg`, puis glisser BOTW Companion dans Applications.

Les deux applications restent autonomes : Python, les données hors ligne,
JoyConDSU et SDL3 sont inclus. Une installation existante peut être remplacée
sans perdre le suivi, les itinéraires ou les préférences.
