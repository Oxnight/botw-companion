## Documentation

- Le README va maintenant droit au but : téléchargement, fonctions principales
  et liens vers les guides utiles.
- L'installation, le gyroscope DSU, le dépannage et le développement disposent
  chacun de leur propre guide.
- Un journal des versions retrace les changements importants depuis le premier
  installateur autonome.
- Le guide de contribution précise les tests à lancer et les fichiers qui ne
  doivent jamais être publiés.
- Le workflow vérifie les documents, leurs liens et leur présence dans les deux
  applications.

Cette version ne change ni l'interface, ni l'analyse des sauvegardes, ni le
moteur gyroscopique.

## Installation

- Windows 10/11 x64 : télécharger le fichier `Setup.exe`.
- macOS 14 ou ultérieur sur Apple Silicon : télécharger le fichier `.dmg`, puis
  glisser BOTW Companion dans Applications.

Python, les données hors ligne, JoyConDSU et SDL3 sont toujours inclus. Une
installation existante peut être remplacée sans perdre le suivi, les
itinéraires ou les préférences.
