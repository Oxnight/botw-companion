# Russian localization — incremental draft

This branch contains the disabled Russian locale and translated application
interface, built-in help and tutorial. Game-guide/report messages and prose are
intentionally absent; no untranslated copies or fallback count as coverage.

Stage: 2 of 4 planned contributions (shared fixes, interface/help, names,
guides/prose). Game names and trial titles are reserved for the next contribution.

The locale stays `enabled: false`. It is unavailable in the installed language
selector. Ordinary generation continues to build only French and English.
Coverage reports the supplied subset; a partially translated locale must not
be enabled. Full Russian compilation and native/gameplay review follow once
all resources are supplied.

No installer or CP1251 changes are included. The translation was edited with
AI assistance and reviewed editorially; automated checks do not establish
independent human approval or certify every official name.
